### 🫀 Cardiovascular Disease Prediction

<a href="https://github.com/jiya-patel24/Cardiovascular-Disease-Prediction">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=jiya-patel24&repo=Cardiovascular-Disease-Prediction&theme=nord&bg_color=161B22&border_color=30363D&title_color=58A6FF&icon_color=A371F7&text_color=F0F6FC" alt="Cardiovascular Disease Prediction" />
</a>

Predicts cardiovascular disease from about 68.6k patient records by comparing 5 machine learning models. Random Forest scored best at **73.0%** test accuracy (Logistic Regression was almost tied at 72.93%). This is an educational project and is **not** meant for medical diagnosis.

| Layer | Technology |
| --- | --- |
| Language | Python |
| Data handling | pandas, NumPy |
| Modeling | scikit-learn (5 models compared, Random Forest best) |
| Visualization | Matplotlib, Seaborn |
| Environment | Jupyter Notebook / Google Colab |

### 🌐 Network Resilience Analyzer

<a href="https://github.com/jiya-patel24/Network-Resilience-Analyzer">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=jiya-patel24&repo=Network-Resilience-Analyzer&theme=nord&bg_color=161B22&border_color=30363D&title_color=58A6FF&icon_color=A371F7&text_color=F0F6FC" alt="Network Resilience Analyzer" />
</a>

Finds single points of failure (articulation points) in a network graph, ranks each one by how many nodes it would cut off if it failed, and updates that analysis incrementally when new nodes are added instead of recomputing everything. Includes an attack simulation that compares targeted vs. random node failure. A D3.js visualization dashboard is planned.

| Layer | Technology |
| --- | --- |
| Language | Python (no external libraries) |
| Data structure | Graph stored as an adjacency list |
| Algorithm | Tarjan's algorithm for articulation points |
| Features | Severity scoring, incremental updates, attack simulation |
| Testing | Built-in PASS/FAIL tests and edge-case tests |

🔗 [**Code**](https://github.com/jiya-patel24/Network-Resilience-Analyzer)
